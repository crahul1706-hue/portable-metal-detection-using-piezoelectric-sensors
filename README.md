# portable-metal-detection-using-piezoelectric-sensors

## 📌 Project Overview

This project presents a portable metal detection system that combines piezoelectric energy harvesting with metal detection technology. The proposed design uses piezoelectric sensors to convert mechanical pressure or vibrations into electrical energy. The harvested energy is rectified, regulated, and stored in a rechargeable battery to support the portable detection system.

The system detects nearby metallic objects using a metal detector sensor and provides an indication through an output device such as an alarm or display.

## 🎯 Objectives

- Develop a compact and portable metal detection system.
- Explore piezoelectric sensors for mechanical energy harvesting.
- Convert harvested AC voltage into DC using a rectifier.
- Regulate voltage using a Zener diode.
- Store energy in a rechargeable battery.
- Provide an alert when a metallic object is detected.

## ⚙️ Working Principle

The system consists of the following stages:

1. **Piezoelectric Sensors:** Convert applied pressure or mechanical vibrations into electrical energy.
2. **AC-to-DC Rectifier:** Converts the generated AC voltage into DC.
3. **Zener Diode Voltage Regulator:** Helps limit voltage and protect the circuit from excessive voltage.
4. **Rechargeable Battery:** Stores electrical energy for powering the detection system.
5. **Metal Detector Sensor:** Detects metallic objects using changes in electromagnetic fields.
6. **Output Unit:** Provides an indication of metal detection through an alarm or display.

## 🔲 System Architecture

```text
Piezoelectric Sensors
```
